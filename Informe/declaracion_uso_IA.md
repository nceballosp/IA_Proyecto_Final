# Declaración de uso de inteligencia artificial generativa

Durante el desarrollo del proyecto se utilizó **ChatGPT/Codex** como apoyo para revisar el código de búsqueda A*, para hacer la comparación con UCS, para arreglar la estructura de la recuperación RAG y como apoyo para hacer el dashboard en streamlit. También se utilizó para preparar borradores de texto para el informe.

Las respuestas generadas por estas herramientas se consideran apoyo, cabe aclarar que se reviso todo el codigo generado para que funcionara de la mejor manera.
